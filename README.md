# TTA AI-Ready 표준화 · 문서 지도

AI-Ready 표준화 전략과제의 문서 체계 지도와 규범 개정안(운영요령·작성지침), 별표·별지 서식, 별표 1 절차도(AI-Ready 접점)를 한 페이지에서 열람하는 정적 웹페이지입니다.

- 좌측 메뉴로 문서 전환, 본문의 별표·별지·조문·작성지침 조항을 클릭하면 **스택형 팝업**으로 해당 부분을 바로 확인
- 완전 자립형(외부 로드 없음) — GitHub Pages 또는 로컬 브라우저에서 그대로 실행

## GitHub Pages 게시
Settings → Pages → Source 를 `main` 브랜치 루트로 지정하면 `https://suntae-kim2020.github.io/tta/` 에서 열립니다.
